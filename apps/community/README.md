# Family & Community (BrickOS)

*"Can we organize, trust, and help each other?"*

The social layer that runs across all BrickOS pillars -- trust scores, mutual aid, family safety, and community coordination.

## Cross-Cutting Services

- **Trust Score Engine** -- Reputation earned through trades, feedback, and participation (Rookie to Arbiter)
- **Peer Feedback** -- Post-trade reviews build community trust
- **Mutual Aid** -- Resource pooling, labor sharing, emergency response coordination
- **Family Safety** -- Dead man's switch, reunion protocol, location sharing (opt-in, encrypted)
- **Escrow Vaults** -- Collateral deposits backing trade integrity
