## STEP 2: Terminology Standardization (B-0094)

### Rule
| Old (kill these) | New (use this) |
|---|---|
| blood marker | Biomarker |
| health marker | Biomarker |
| Marker (standalone, user-facing) | Biomarker |
| Blutmarker | Biomarker |
| Gesundheitsmarker | Biomarker |
| markers (lowercase plural) | Biomarker (or "Biomarkers" in EN plural context) |

**Exception:** Internal code identifiers (variable names, DB columns, API fields) can stay as `marker`/`markers` — this is a USER-FACING text change only.

### i18n keys to update/create

In both EN and DE translation JSON files:

```json
// EN
{
  "common.biomarker": "Biomarker",
  "common.biomarkers": "Biomarkers",
  "common.biomarkerCount": "85+ Biomarkers",
  "markers.pageTitle": "Biomarkers",
  "markers.pageSubtitle": "Track and understand your health with 85+ biomarkers across 8 Health Zones",
  "healthZones.markerCount": "85+ Biomarkers"
}

// DE
{
  "common.biomarker": "Biomarker",
  "common.biomarkers": "Biomarker",
  "common.biomarkerCount": "85+ Biomarker",
  "markers.pageTitle": "Biomarker",
  "markers.pageSubtitle": "Verfolge und verstehe deine Gesundheit mit 85+ Biomarkern in 8 Gesundheitszonen",
  "healthZones.markerCount": "85+ Biomarker"
}
```

Replace every hardcoded user-facing "marker"/"blood marker"/"health marker" with the appropriate i18n key.
