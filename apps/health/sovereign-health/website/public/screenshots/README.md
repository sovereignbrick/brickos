# App Screenshots

Drop screenshots here using this naming convention:

```
01-dashboard.png
02-doctor-chat.png
03-measurements.png
04-trends.png
05-health-zones.png
06-settings.png
...
```

**Format:** `{order}-{slug}.png` (or `.jpg`/`.webp`)

- The number determines display order on the website
- The slug is used for alt text and captions (dashes become spaces)
- First 3 images appear on the homepage hero section
- All images are available for the Learn page and other sections

**Recommended:** 1920x1080 or 1280x720 PNG, dark theme preferred.
