# Start9 Package for Sovereign Link

## Building

1. Install start-sdk: https://docs.start9.com/latest/developer-docs/
2. Build: `start-sdk pack`
3. Install on your Start9: sideload the .s9pk file

## Development

The Start9 package wraps the same Docker image used for standalone deployment.
The manifest.yaml defines the service configuration, health checks, and interfaces.

## Icon

Replace icon.png with a 256x256 PNG icon for the Start9 marketplace.
