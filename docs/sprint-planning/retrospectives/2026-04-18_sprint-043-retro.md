# Sprint 043 Retrospective -- SHI Production Push

**Date:** 2026-04-18
**Sprint:** 043

## What went well

1. **Phase A was much smaller than estimated.** The sprint spec estimated 1-2 days
   for the licensing cutover. Investigation revealed `check_feature` had zero
   callers -- the real live path was `check_tier_feature`. The cleanup was 30
   minutes instead of 2 days.

2. **#529 AI config from app_settings works end-to-end.** Changed the model from
   the platform admin settings page, Dr. Alex used it on the next request. Zero
   hardcoded model strings remain. The operator control plane works as designed.

3. **White-label test (Phase E) passed cleanly.** Org creation, branding, license
   issuance, member management, seat enforcement all work. The 6th practitioner
   was correctly blocked at 5/5.

4. **Design-first approach paid off for #526.** Design 015 was signed off before
   any code, and the 4 decision points (D1-D4) guided every nginx change.

## What didn't go well

1. **The nginx routing for brickos.io took 4 iterations to get right:**
   - First: added /api/, /auth/, /admin/ blocks -- missed auth_basic off
   - Second: added auth_basic off -- but sovereignhealth.io frontend called /api/auth/login (wrong prefix)
   - Third: reverted sovereignhealth.io to legacy API subdomain -- but /zones etc. missing on brickos.io
   - Fourth: regex-based block covering all 30 backend route prefixes -- finally correct
   
   **Lesson:** When adding nginx path-mount blocks, enumerate ALL backend route
   prefixes upfront. Don't add 3 and assume the rest don't matter.

2. **SSH to VPS kept dropping during image transfers.** Three failed deploys due
   to `Broken pipe` during `docker save | ssh docker load`. Fixed by switching
   to `docker save | gzip > file && scp file` approach.
   
   **Lesson:** Use file-based transfer (scp) not pipe-based (docker save | ssh)
   for images over slow/unstable connections.

3. **Rate limiter cascades blocked Playwright E2E runs.** Each test calls
   `loginAndNavigate` separately, and 11 tests = 11 login attempts. The
   in-memory rate limiter trips after ~5 attempts and all subsequent tests fail.
   
   **Lesson:** E2E tests that run against staging need either: (a) a shared
   login session across tests, or (b) a rate-limiter bypass for test IPs,
   or (c) a `beforeAll` login that reuses the token.

4. **Model ID `claude-sonnet-4-5-20250514` doesn't exist.** The seed migration
   had a wrong model name. Staging Dr. Alex was broken until we fixed it via
   the platform admin settings page.
   
   **Lesson:** Validate model IDs against the Anthropic API before seeding them.
   The app_settings approach let us fix this without a redeploy -- exactly the
   flexibility #529 was designed to provide.
