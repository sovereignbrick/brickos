## What Went Well

1. **Design-first approach paid off again** -- L1/L2/L3 licensing architecture was designed before code, resulting in clean implementation with no rework. User journeys caught the org-billing-anchor question early.

2. **SSoT migration was clean** -- tier_features enforcement replaced 30+ legacy columns without breaking any existing tests. Incremental approach (add new functions, migrate callers one-by-one) worked perfectly.

3. **Parallel task execution** -- background agents for T5/T10 research while working critical path T7/T8/T9 maximized throughput.

4. **RC testing on staging caught real issues** -- demo data missing (UUID mismatch), legacy quota blocking chat, admin bypass, measurement count including demo data. All fixed before production.

5. **138 tests** -- 25 new tests added (9 SSoT, 11 calculated marker, 8 reference range). Test suite now covers business logic, not just API shape.

---

## What Didn't Go Well

1. **Demo user UUID mismatch** -- the demo user was registered manually before the seed migration, causing `ON CONFLICT (email) DO NOTHING` to silently skip. Cost ~30 min to diagnose and fix on staging. **Fix:** seed migrations should use `ON CONFLICT DO UPDATE` for critical seed data, not `DO NOTHING`.

2. **Legacy doctor_chat_quota not cleaned up initially** -- the old quota system was still being called alongside the new AI credit pool, causing "999 of 0 remaining" display. Required 3 iterations to fully remove. **Fix:** when replacing a system, grep for ALL references before declaring it done.

3. **deploy.sh keeps bumping VERSION to -b1** -- every staging deploy changes lib.rs VERSION, breaking snapshot tests. Had to fix VERSION 5+ times. **Fix:** deploy.sh should not modify source files that affect test snapshots, or tests should not assert on version strings.

4. **Chat scroll took 3 attempts** -- `overflow-y-auto` alone wasn't enough; needed `min-h-0 overflow-hidden` on every flex ancestor. CSS flex height constraint chains are non-obvious. **Fix:** document the flex scroll pattern for future reference.

5. **Settings tab iteration** -- went through 4 tab naming/layout iterations (short labels, full labels, merged tabs, restored tabs). Could have aligned on the final layout before starting code. **Fix:** sketch UI changes before implementing.

6. **Sprint extended from 2 to 3 days** -- bonus work (reference ranges, business logic docs, settings restructure) was valuable but unplanned. **Fix:** accept that RC testing always surfaces additional work; budget 30% buffer.
