## What went well

1. **Marker coverage dramatically improved** -- 24 alias fixes + 5 new markers + migration in a single sprint. Import matching is now robust for European lab naming.
2. **Fast turnaround on user-reported issues** -- UA alias, GGT investigation, and FSH/Total Fatty Acids identified and tracked within the same session.
3. **Notification infrastructure fixed end-to-end** -- ntfy DNS proxy removed, stale token found and replaced, all 5 channels tested, 3 new hooks added (contact, newsletter, migration failure), deploy pre-flight check added.
4. **Tier gating** for Smart Import added to both welcome screen and upload menu -- clean UX with lock icons.
5. **Full deploy cycle** -- local dev → RC test → staging → production in one session.
6. **Migration audit** -- 118/118 checksums verified clean. Good hygiene.

## What didn't go well

1. **Version number churn** -- lib.rs VERSION was modified externally multiple times during the session, causing repeated deploy failures. The deploy script's exact-match check caught it every time (good), but it cost ~30 min of retry cycles.
2. **ntfy token was stale since initial setup** -- notifications were silently failing in production since launch. No pre-flight check existed. Now fixed, but this was a gap.
3. **Website build failures** -- stale `.next` cache and TypeScript type mismatch (`feature-comparison-table.tsx`) blocked two deploy attempts. The `as unknown as` cast is a band-aid.
4. **docker-compose.dev.yml** had wrong frontend context since creation -- never caught because frontend was rarely built locally via compose.
5. **Deploy script ran from wrong branch** -- production deploy failed once because we were on `develop` instead of `main`. The script caught it, but the error message could be clearer upfront.
