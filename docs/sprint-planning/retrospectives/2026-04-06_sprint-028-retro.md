# Sprint 028 Retrospective - Sovereign Link Platform Mode

**Date:** 2026-04-06
**Sprint:** 028 - Sovereign Link Platform Mode + BrickOS Schema Elevation
**Duration:** 1 day (5 logical "days" compressed)

## What went well

- **Audit-first approach** saved time: 12 of 18 M1 issues were already done from Sprint 027. Auditing before building prevented duplicate work.
- **Schema elevation design** was thorough: 3 design docs (003, 004, 005) covered all angles before writing SQL. The table classification (39 platform, 53 SHI, 10 ambiguous) gave clear scope.
- **Integration tests** caught the API auth middleware gap (#316). Without the test suite, standalone API access would have shipped broken.
- **Migration safety**: all SQL uses IF EXISTS, no columns dropped, search_path backward compatibility. Zero-downtime design validated by the team.
- **Feature flags work**: `--features standalone` and `--features platform` compile independently. Clean separation.

## What didn't go well

- **Deployment workflow was not followed.** Sprint artifacts (retro, release notes, version bump) were not created before PR. This was caught during PR review.
- **Deployment doc was SHI-specific.** No platform-level deployment workflow existed. Had to create it during sprint closing.
- **NIP-89 publishing is incomplete**: signs events correctly but has no WebSocket relay client (needs tungstenite crate). Falls back to logging.
- **Platform migrations are untested on staging.** SQL is written and reviewed but not executed against the actual database yet.
- **GitHub GraphQL API rate limits** blocked issue creation initially. Had to fall back to REST API.

## What to change

- **Always create sprint artifacts BEFORE the PR.** Add a pre-PR checklist to the deployment workflow.
- **Elevate the deployment workflow first** when adding new apps, not as an afterthought.
- **Add tungstenite dependency** for NIP-89 and future NOSTR relay communication.
- **Test platform migrations on staging** before merging the PR. This is the critical path.
- **Add Sovereign Link and Sovereign Voice to Gatus monitoring.**
