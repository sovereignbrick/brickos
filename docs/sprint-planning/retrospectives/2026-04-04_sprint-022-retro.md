## What Didn't Go Well

1. **brickos.io required 6 iteration cycles** -- contact form (wrong endpoint, missing subject field, CORS), logo background (color mismatch, grain overlay), text readability (dim colors), em dashes. Each fix needed a rebuild + rsync deploy.

2. **CORS not caught in development** -- contact form worked on localhost but failed on production because brickos.io wasn't in CORS allowed origins. Should test cross-origin calls during development.

3. **Production deploy branch confusion** -- multiple deploy attempts failed because of branch state (on develop instead of main, uncommitted files, lockfile mismatch). Five failed production deploy attempts.

4. **GraphQL rate limit = 0** -- cannot create GitHub Discussions via API. This account limitation keeps coming up. Seed discussions had to be written for manual posting.

5. **Encrypted contact data in admin** -- forgot that name/email are AES-encrypted in contact_submissions. Admin endpoint returned ciphertext. Required adding Encryptor to the handler.

---

## Key Lessons

1. **Test cross-origin early** -- when building a site that calls an API on a different domain, test the actual CORS preflight before deploying. Add the origin to the API CORS config as part of the initial setup.

2. **Static site iteration is fast** -- Next.js static export + rsync takes ~15 seconds to deploy. Use this speed to iterate rapidly on visual issues.

3. **Brand guide HTML assets need adaptation** -- iframe-embedded HTML files carry their own styles (background, grain overlay) that conflict with the parent page. Strip conflicting styles when embedding.

4. **No em dashes** -- established as a project-wide rule. Use hyphens (-) or double hyphens (--) everywhere.

5. **Encrypted fields need decryption in admin** -- any admin endpoint reading from encrypted tables must inject the Encryptor and decrypt before returning.
