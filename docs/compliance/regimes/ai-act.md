## 1. Applicability

BrickOS deploys an AI system ("Dr. Alex") that provides health-related analysis based on user biomarker data using the Anthropic Claude API.

- [ ] Applies indirectly (through supply chain, sector rules)
- [ ] Does not apply (with reasoning)

**Classification:** **Limited-risk AI system** (Art. 50 transparency obligations)

**Risk classification rationale:**

- Dr. Alex does NOT autonomously diagnose, treat, or make medical decisions
- It is an assistive, informational tool -- users ask questions, AI responds with analysis
- No automated decision-making that produces legal effects (Art. 6 / Annex III exclusion)
- It is NOT a medical device (no CE marking, no diagnostic claims)
- Users voluntarily engage with the AI; all output is advisory
- Classification: AI system that interacts with natural persons (Art. 50(1)) -- limited risk

**Why NOT high-risk (Annex III, point 5):**
Annex III, point 5(b) covers AI systems "intended to be used to evaluate the eligibility of natural persons for health care services." Dr. Alex does not evaluate eligibility -- it provides informational analysis of user-supplied biomarker data. It does not triage, diagnose, prescribe, or gate access to healthcare. Users are always informed the output is not medical advice.
