# FIDA (Financial Data Access Regulation) -- Compliance Assessment

**Status:** NOT APPLICABLE
**Last reviewed:** 2026-04-06
**Next review:** 2027-04-06 (annual)

## Applicability Assessment

FIDA regulates access to and sharing of financial data (bank accounts, insurance, pensions, investments). BrickOS handles health biomarker data, not financial data. Bitcoin payment processing is delegated to Strike and Stripe -- BrickOS does not store financial account data, transaction histories, or payment credentials. No financial data is held or shared by the platform.

## Conditions for Re-evaluation

- BrickOS begins storing or processing financial data (bank accounts, investment portfolios)
- BrickOS integrates with open banking APIs or financial data aggregators
- FIDA scope expands to cover health-adjacent financial data (e.g., health insurance claims)
