## Description

Unified admin GUI for BrickOS platform and organization management. One codebase, role-based content filtering (BrickOS admin, Owner, Tech Admin, Commercial Admin). Elevates 16 of 17 SHI admin tabs to platform level.

Reference: docs/design/014-brickos-platform-gui.md

## Phases

- Phase 1 (Sprint 031): Foundation -- layout, dashboard, users, service monitor
- Phase 2 (Sprint 032): Commerce + content elevation
- Phase 3 (Sprint 033): Analytics + AI + compliance
- Phase 4 (Sprint 034): Org self-service + on-prem licensing
