## Description
NIS 2 Art. 23 requires incident reporting to national CSIRT. For Germany: BSI (Bundesamt fur Sicherheit in der Informationstechnik).

Currently only required when above size threshold. Document process proactively.

## Action
- [ ] Register with BSI incident reporting portal
- [ ] Document reporting procedure and timelines (24h initial, 72h update)
- [ ] Add to incident response procedure
